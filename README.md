# Engenharia de Software — Infnet

Projects and assignments developed during my Software Engineering major at [Infnet](https://www.infnet.edu.br).

Each directory is a course, and each course has one directory per assignment (`tp1`, `tp2`, ..., `at`). Courses are grouped below by the block they belong to. Quarter codes follow Infnet's own (`24E2` is the second quarter of 2024).
